# Security policy

Please report suspected vulnerabilities privately through GitHub’s private vulnerability-reporting channel for this repository. Do not publish credentials, raw evidence, customer identifiers, personal data, tokens, or exploit details in issues, discussions, fixtures, or pull requests.

ccm-casework is a local workflow-artifact package. It does not authenticate approval actors, enforce authorization policy, contact cloud providers, retain payloads, operate a scheduler, or execute remediation. Deployer-side identity, access control, evidence retention, notification, and risk-governance controls remain required.
